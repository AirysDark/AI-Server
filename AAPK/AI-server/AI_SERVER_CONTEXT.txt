WSGI HISTORY
============================================================

A PythonAnywhere adapter is used to connect the existing HTTP AIHandler to
the PythonAnywhere WSGI environment.

A previous error was:
    AttributeError: 'WSGIHandler' object has no attribute 'directory'

This happened because Python 3.13's SimpleHTTPRequestHandler expected the
handler to have a directory attribute.

The WSGI adapter was updated to handle the Python 3.13 environment correctly.

A separate temporary typo was:
    from wsgi import applicatio

Correct:
    from wsgi import application
